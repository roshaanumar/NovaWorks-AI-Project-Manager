## Brand & Style

This design system embodies high-velocity enterprise clarity: razor-sharp modern precision, ambient intelligence, and an authoritative yet luminous atmosphere. It is engineered for executives, product leaders, and high-performance cross-functional engineering teams who depend on zero-friction project orchestration and instant transformation of ambiguous meeting audio into actionable structure.

The design movement combines **Contemporary Enterprise Precision** with **Controlled Glassmorphic Luminescence**. Clean, high-density light canvases set an ergonomic baseline for data synthesis, while deep obsidian slate chrome provides spatial focus. Intelligent automated states are punctuated by restrained indigo-to-electric-blue gradients and micro-glow accents, signifying real-time machine intelligence without distracting novelty.

## Colors

The palette establishes high contrast and distinct functional zoning:

- **Primary (`#4F46E5` / `#6366F1`)**: Reserved for high-intent focal actions, AI synthesis states, active task conversions, and interactive selections.
- **Secondary (`#0F172A` / `#1E293B`)**: Anchors primary structural frames, deep global sidebars, dark command bars, and primary text hierarchies.
- **Tertiary (`#3B82F6`)**: Contextual actions, real-time audio waveforms, active filtering, and link highlights.
- **Neutrals & Canvases (`#F8FAFC`, `#F1F5F9`, `#E2E8F0`, `#64748B`)**: Layered base surfaces providing clean contrast with low-contrast slate dividers (`#E2E8F0`).
- **Semantic Accents**:
  - Success / Conversion: Emerald (`#10B981`)
  - Warning / In-Progress: Amber (`#F59E0B`)
  - AI Synthetic Gradient: Subtle blend from `#4F46E5` through `#3B82F6` with 12% alpha backdrops.

## Typography

Typography balances structural authority with scannable utility:

- **Display & Headlines (`Plus Jakarta Sans`)**: Delivers geometric warmth, contemporary executive authority, and tight character metrics for dashboards, project boards, and modal titles.
- **Body & Controls (`Inter`)**: Highly optimized for complex layout density, transcripts, data tables, and high-frequency reading.
- **Tabular Figures**: All metrics, timestamps, time tracking, and numerical column cells enforce OpenType tabular figures (`font-variant-numeric: tabular-nums`) to maintain alignment across fluctuating data views.

## Layout & Spacing

The layout philosophy uses a disciplined **12-column adaptive fluid grid** with a fixed global vertical navigation rail on desktop screens:

- **Desktop (1280px+)**: 12-column layout with 24px (`1.5rem`) gutters and 32px (`2rem`) outer canvas margins. Persistent dark slate sidebar (260px expanded, 72px collapsed). Transcripts, AI output panels, and task kanbans split into synchronized multi-pane views.
- **Tablet (768px - 1279px)**: 8-column layout with 20px gutters and 24px margins. Sidebar transitions to an icon-only dock or off-canvas drawer. Split panels become tab-switchable.
- **Mobile (< 768px)**: 4-column layout with 16px (`1rem`) gutters and 16px (`1rem`) outer margins. Bottom navigation bar takes over core switching; project data switches from broad tables to touch-optimized cards.

## Elevation & Depth

Visual hierarchy uses a refined hybrid of **low-contrast micro-outlines and ambient directional diffusion**:

- **Layer 0 (Canvas Base)**: `#F8FAFC` flat surface.
- **Layer 1 (Card & Content Blocks)**: `#FFFFFF` surface enclosed by a 1px micro-border of `#E2E8F0` and an ambient drop shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Layer 2 (Hovered Cards & Dropdowns)**: Elevated `#FFFFFF` surface with micro-border `#CBD5E1` and ambient shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.06), 0 4px 6px -4px rgba(15, 23, 42, 0.03)`.
- **Layer 3 (Modals, Overlays & Command K)**: Layered with a backdrop blur (`backdrop-filter: blur(12px)`) over a 40% `#0F172A` scrim, bordered by `rgba(226, 232, 240, 0.8)`, cast with `0 25px 50px -12px rgba(15, 23, 42, 0.18)`.
- **AI Glowing Elevation**: AI conversion prompts, active voice-processing states, and generated project banners apply a subtle electric border halo: `0 0 0 1px rgba(99, 102, 241, 0.3), 0 4px 20px -2px rgba(79, 70, 229, 0.12)`.

## Shapes

The shape system leverages structured curvaceousness that feels ergonomic without sacrificing data density:

- Standard elements (buttons, inputs, status tags, list cells) use base curvature (`0.5rem` / `rounded-md`).
- Primary content containers, transcript transcriptions, and kanban cards use `rounded-xl` (`1rem`).
- Floating AI summary banners, dialog modals, and global command menus use `rounded-2xl` (`1.5rem`).
- Micro status tags, avatars, and pill filter buttons utilize fully rounded ends (`9999px` / pill-shaped).

## Components

### Buttons
- **Primary**: Solid `#4F46E5` background, `#FFFFFF` text, `0.5rem` radius, subtle top inner-bevel (`box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.15)`). Hover triggers `#4338CA`.
- **AI Action Button**: Vibrant gradient (`linear-gradient(135deg, #4F46E5, #3B82F6)`), glowing subtle aura on hover, white text with leading sparkle/magic icon.
- **Secondary**: `#FFFFFF` background, 1px `#E2E8F0` border, `#0F172A` text. Hover shifts to `#F8FAFC` and `#CBD5E1`.
- **Ghost/Tertiary**: Transparent background, `#64748B` text, hovers to `#F1F5F9` and `#0F172A`.

### Status Badges & Pills
- Pill-shaped (`rounded-full`), height of 24px, padding 2px 10px, typography `label-sm`.
- **AI Extracted / Pending**: 10% alpha indigo background (`#EEF2FF`), solid `#4F46E5` text, left dot indicator with subtle pulse animation.
- **Done / Converted**: Light emerald background (`#ECFDF5`), `#047857` text.
- **Blocked / Attention**: Light amber background (`#FFFBEB`), `#B45309` text.

### Cards & AI Insights Panel
- High-level containers feature white surface backgrounds with a distinct micro-border (`#E2E8F0`).
- **Transcript-to-Task Stream Card**: Split view containing verbatim snippet on the left with light grey background (`#F8FAFC`), and structured task breakdown on the right with an animated indigo connector line indicating extraction confidence.

### Data Tables
- Clean tabular view with `#F8FAFC` headers, `#64748B` label tokens, and uppercase tracking.
- Row heights pegged at 48px with 1px bottom border (`#F1F5F9`). Alternates row hover state to `#F8FAFC` with active checkbox visibility. Numeric values formatted via tabular numbers.

### Input Fields & Search Bars
- Background `#FFFFFF`, 1px border `#E2E8F0`, `0.5rem` radius, typography `body-md`.
- Focus state: Border transitions to `#6366F1` with an outer ring `box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.15)`.

### Checkboxes & Radios
- 16px square/circle with `0.25rem` radius (or circle for radio). 1px border `#CBD5E1`. Active state fills `#4F46E5` with sharp white icon checkmark.

### App Shell & Navigation
- **Sidebar**: Deep obsidian `#0F172A` surface, `#94A3B8` icon/text navigation links, active states highlighted with `#FFFFFF` text and subtle translucent indigo fill (`rgba(99, 102, 241, 0.15)`).
- **Responsive Mobile Dock**: Bottom navigation bar with frosted glass backdrop blur (`rgba(15, 23, 42, 0.95)` on dark mode, or `rgba(255, 255, 255, 0.9)` on light canvas) with top edge micro-border.
